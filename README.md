# Paleotype

Paleotype is a browser-based tool designed for the manual transcription of historical documents. It provides a split-screen interface to view digital surrogates (images or PDFs) while transcribing the text in a clean, distraction-free editor.

## Access
You can access the application at: 
`https://foxvoss.github.io/paleotype/index.html`

## Local Usage (Offline)
Paleotype is designed to be fully portable. You do not need to use the GitHub link to run the application:
1. **Download:** Save the `index.html` file to your local device.
2. **Run:** Open the file in any modern web browser.
3. **Privacy:** When used locally, the application remains fully functional without an internet connection. No data ever leaves your computer.

## Core Features

- **Format Support:** Compatibility with PDF, JPG, PNG, and WEBP files.
- **Image Enhancement:** Integrated controls for brightness and contrast, and an invert (negative) mode to improve the legibility of faded or dark manuscripts.
- **Navigation:** Page-specific navigation for multi-page PDF documents, including a direct page-jump input.
- **No Automated Interference:** Spellcheck and auto-correct are disabled by default to prevent the unintended alteration of archaic spelling, regional dialects, or paleographic notations.
- **Export Options:** Transcription data can be copied to the clipboard or downloaded as a plain text file (.txt) using UTF-8 encoding to preserve special characters and diacritics.
- **Multilingual Interface:** Available in English, Dutch, German, French, Spanish, and Italian.

## Privacy and Security

- **Local Processing:** All file processing and text entry occur locally within the user's browser. Even when accessed via GitHub Pages, the actual processing is done on the client side.
- **Persistence:** Text is automatically cached in the browser's local storage to prevent data loss during accidental refreshes.

## Instructions for Use

1. **Load Document:** Select an image or PDF from your local device.
2. **Adjust View:** Use the filter panel in the top-right corner to adjust the visual properties of the document for better readability.
3. **Transcribe:** Enter the text in the editor pane below the viewer. The divider can be adjusted to change the size of the viewing area.
4. **Export:** Use the Export menu to save your work or copy it to the clipboard.
